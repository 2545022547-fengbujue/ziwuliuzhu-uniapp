### 2. 编译环境（关键根因）
- **HBuilderX 必须以「PATH 最前注入内置 node22」方式启动**，否则编译进程加载 node22
  字节码（uni_helpers 等）报 `cachedDataRejected`。且 cli spawn 的编译进程自带
  `-r kill.js` 心跳（每 3 秒检查 HBuilderX 主进程存活，失败则静默自杀），
  任何手动复刻编译时若不带正确环境会得到无提示的进程死亡。
- CLI 布局项目（有 package.json/node_modules）的编译进程以项目根为 cwd，
  `isInHBuilderX()` 为 false，走项目自身 npm 工具链；此时**vue/@vue/shared 版本
  必须与工具链对齐到 3.4.21**（uni-app x 5.24 工具链按 vue 3.4.21 构建），
  否则打包期报 `"normalizeCssVarValue" is not exported by .../@vue/shared/...`。

### 3. 依赖版本漂移（多次 npm 操作造成，已全部对齐）

| @dcloudio/uni-app-x | 0.7.114/0.7.132 漂移 | 保持 0.7.114（云端打包验证可用） |

### 4. 蒸汽模式代码适配（本次完成的迁移工作）
- **CSS 适配**（uvue 原生渲染是 web CSS 子集，60+ 处编译错误清零）：
  - `@keyframes` App 端完全不支持（连 `0%/100%` 选择器都不行）→ 全部用
    `/* #ifndef APP */` 包裹保留 Web 动画，App 端动画待用 `UniElement.animate()` 重做；
  - `display: block/inline-flex` → App 端 `flex`（条件编译双轨，Web 视觉不变）；
  - `100vh/70vh/85vh/50vh` → App 端 `100%`/固定 px（max-height 不支持百分比）；
  - `max-width: 100%`、`text-align: justify`、`background: inherit` → 条件编译双轨；
  - `radial/conic-gradient` → Web 保留、App 端 linear-gradient 近似（主题色卡预览）；
  - `:hover`/`:active`/`:first-child`/`:last-child`/`:nth-child`/`::-webkit-scrollbar`/
    `>uni-text` 等选择器 → 条件编译双轨；
  - `.animal-loading-dots .dot:nth-child(2/3)` → 模板加 `dot2/dot3` 类改为单类选择器。
- **SCSS 变量注入**：蒸汽发行预编译管线不读取 vite 的 scss `additionalData`，
  全局变量改由 `src/uni.scss` `@use "@/styles/variables.scss" as *;`（uni 约定机制，
  覆盖所有编译路径）。
- **lunar-javascript CJS 互操作**：uts2js/rollup 无 commonjs 互操作，静态 import
  （具名/default）均报 not exported。`services/ganzhi.js` 改为条件编译：
  App 端 `require()`（最终 vite 打包由 commonjs 插件转换），Web/MP/vitest 保持 ESM import。
- **类型导入**：`setting.uvue` 的 `AppStore` 改为 `import type`（否则被 twin 生成器
  当作值导入，rollup 报 not exported）。
- **store 引用**：恢复的真实首页 `index.uvue` 里 `@/stores/app.js` → `@/stores/app.ts`。

## 三、遗留事项（按优先级）
1. **git 提交**：本次所有修复未提交（仓库仅有一个基线提交）。建议先
   `git add -A && git commit` 快照当前可用状态。
2. **包名正式录入**：dev.dcloud.net.cn → 应用详情 → 各平台信息 → 添加 Android 包名
   `com.chaihu.zwlz`（当前是 --ignoreWarnings 自动登记的测试包名）。
3. **App 端动画**：@keyframes 在蒸汽模式不可用，主题过渡/加载动画在 App 端暂时
   静态化。后续可用 `UniElement.animate()` API 重做（见官方文档 CSS 差异章节）。
4. **本地字节码开发编译**：要真机热刷开发，需把项目迁到纯英文路径（如
   `D:\zwliuzhu-x`）并在 HBuilderX 配置 Android SDK。已验证「中文路径」不影响
   云端打包。
5. **App 端主题后代选择器**：`.theme-black .xxx` 等在蒸汽 App 端被忽略
   （Invalid selector 警告，非致命）。主题色走 CSS 变量不受影响，个别主题专属
   覆盖样式在 App 端不生效，遇到再逐个补类名方案。
6. **H5/小程序 npm 构建暂不可用**：`npm run build:h5` 在 uts 类型检查阶段报
   `TS2503: Cannot find namespace 'UTSJSONObject'`（src/data/*.uts 与
   scripts/*.js 被 tsc 程序收录的问题）。注意：本会话开始时 npm 构建本就被
   假 vue stub 彻底破坏（vite 配置都加载不了），当前已能进入类型检查阶段，
   属遗留问题而非本次回归。云端打包不受影响。
6. **根/双 vite.config 分工**：根部 vite.config.js 仅用于 Web/MP npm 构建；
   App 构建读 `src/vite.config.js`（本次新增）。两个文件注释里都写明了分工。

## 四、排障速查（新报错先看这里）
| 症状 | 原因 | 处置 |
|---|---|---|
| `cachedDataRejected` | 编译进程用了系统 node24 | HBuilderX 以 node22 注入 PATH 重启 |
| 编译进程 ~10 秒无提示消失 | kill.js 心跳自杀（父进程检测失败） | 用 cli.exe 正常流程，勿手动裸跑编译命令 |
| `The type could not be inferred` | store 未对齐工具链/依赖漂移 | 核对上面的版本表 |
| `normalizeCssVarValue is not exported by @vue/shared` | vue 3.5 与工具链 3.4.21 混装 | vue 系列锁 3.4.21 |
| `Undefined variable $xxx`（发行预编译） | 该管线不读 vite additionalData | 变量走 src/uni.scss 注入 |
| `xxx is not exported by`（CJS 包，如 lunar-javascript） | uts2js 无 commonjs 互操作 | 条件编译：App 用 require，其余 ESM |
| 中文路径报错（Android 编译链） | 本地字节码编译限制 | 迁英文路径或用云端打包 |
